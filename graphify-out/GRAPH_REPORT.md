## 🔍 7. Architectural Bottlenecks & Refactoring Recommendations

1. **Mega-Controller God Nodes**:
   - `ECourtsController` contains **7,988 LOC** and `LabourController` contains **3,392 LOC**.
   - *Recommendation*: Decompose `ECourtsController` into focused controllers: `HighCourtCauseListController`, `NapixSyncController`, `RoznamaController`, and `MyCasesController`.
2. **Persistence Duality**:
   - Cause lists use file-based JSON caching (`App_Data/causelist_cache`), while operational cases use SQL Server (`tbl_MVC_Cases`, `tbl_Labour_Cases`).
   - *Assessment*: This intentional design choice achieves sub-10ms render times during peak morning hours without locking SQL connection pools. However, ensure file system permissions on IIS Application Pools (`IIS_IUSRS`) remain write-enabled.
3. **Database Migration Distributed Lock**:
   - `DatabaseMigrationRunner` uses `sp_getapplock` to prevent migration races across multi-instance IIS clusters.
   - *Assessment*: Highly resilient, production-ready pattern.
